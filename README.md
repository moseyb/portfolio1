# My Portfolio

A personal portfolio website built with HTML, CSS and Bootstrap. It introduces me, Moise Byiringiro, a software development student, and showcases my projects in one clean, responsive page.

## Features

- **About Me section:** a short professional introduction with my profile photo.
- **Projects 1 section:** a list of links to my first group of projects.
- **Projects 2 section:** a list of links to my second group of projects.
- **Responsive layout:** built with the Bootstrap grid so it adapts to different screen sizes.
- **Custom styling:** extra styles for the profile image in `main.css`.

## How to run this project

The project runs locally in a web browser. Anyone can access it by cloning this repository and opening `index1.html`.

Live version (if published with GitHub Pages): `https://github.com/moseyb/portfolio1/`

### Prerequisites

- A modern web browser (Chrome, Edge, Firefox)
- [Git](https://git-scm.com/downloads) to clone the repository
- A code editor such as [VS Code](https://code.visualstudio.com/) (optional, for editing)
- An internet connection, because Bootstrap is loaded from a CDN

### Installation

1. Clone the repo:

   ```bash
   git clone https://github.com/moseyb/portfolio1
   ```

2. Move into the project folder:

   ```bash
   cd portfolio1
   ```

3. Make sure the folder contains `index1.html`, `main.css` and the `image` folder with `project1.jpeg`.

4. Open `index1.html` by double-clicking it, or right-click it and choose **Open with** your browser.
